## What is a self-hosted cloud?

A **self-hosted Vibe Kanban Cloud** adds team collaboration to Vibe Kanban. Your projects, issues and progress sync to a server you run, so your entire team stays in sync.

Without a server, Vibe Kanban runs fully locally: you create workspaces, run coding agents and review their changes, with no sign-in.

### Local only vs self-hosted cloud

| Feature | Local only | Self-hosted cloud |
|---------|------------|-------------------|
| **Workspaces and coding agents** | Yes | Yes |
| **Projects, issues and kanban board** | No | Yes |
| **Data storage** | On your computer | Workspaces on your computer; projects and issues on your server |
| **Team access** | Only you | Invite team members |
| **Sign-in required** | No | Yes (the method your server is configured for) |
| **Works offline** | Yes | Projects and issues need a connection to your server |

## How It Works

1. **Deploy a server** with [Docker Compose](/self-hosting/deploy-docker)
2. **Run Vibe Kanban** with `VK_SHARED_API_BASE` set to your server's URL (see [Connect Vibe Kanban to your server](/self-hosting/overview#2-connect-vibe-kanban-to-your-server))
3. **Sign in** (a personal organisation is created automatically)
4. **Create projects** in your personal organisation
5. **Create a team organisation** if you want to collaborate (optional)
6. **Invite team members** and collaborate in real-time

Your local workspaces remain on your machine. Projects and issues are stored on your server and sync automatically.

## Key Concepts

### Organisations

An **organisation** is your team's shared space. It contains:
- Team members with different roles (Admin, Member)
- Projects that everyone can access
- Shared settings

Think of it as your company or team in Vibe Kanban.

### Projects

A **project** is a kanban board for a specific initiative. Each project has:
- Customisable status columns
- Issues to track work
- Tags for categorisation

### Issues

An **issue** is a single piece of work. Issues have:
- Simple IDs (like `TASK-123`) for easy reference
- Multiple assignees
- Priority levels
- Comments for discussion
- Sub-issues for breaking down work

## Features

### Team Collaboration
- Invite members by email
- Role-based permissions (Admin and Member)
- See who's assigned to what

### Real-Time Sync
- Changes appear instantly for everyone
- No conflicts or manual merging
- Always up to date

### Advanced Kanban
- Drag-and-drop issues between columns
- Custom status columns with colours
- Filter by priority, assignee, or tags
- Multiple sort options

### GitHub Integration
- Link pull requests to issues
- Review code directly in Vibe Kanban
- Track PR status

## Getting Started

<Steps>
<Step title="Deploy your server">
  Follow [Deploy with Docker Compose](/self-hosting/deploy-docker).
</Step>

<Step title="Run Vibe Kanban against your server">
  ```bash
  VK_SHARED_API_BASE=https://vk.example.com npx vibe-kanban
  ```
</Step>

<Step title="Sign in">
  Click **Login** and sign in with the method your server is configured for. A personal organisation is created automatically.
</Step>

<Step title="Create a project">
  Click **+ New Project** and start adding issues.
</Step>

<Step title="Create team organisation (optional)">
  To collaborate, create a new organisation from the user menu and invite members by email.
</Step>
</Steps>
