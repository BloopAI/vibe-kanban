<Steps>
<Step title="Run OpenCode">
  ```bash
  npx -y opencode-ai
  ```
</Step>

<Step title="Follow the login instructions">
  Complete the authentication flow as prompted. For more details, see the [OpenCode GitHub page](https://github.com/sst/opencode).
</Step>

<Step title="Start Vibe Kanban">
  Once authenticated, launch Vibe Kanban:

  ```bash
  npx vibe-kanban
  ```

  You can now select OpenCode when creating task attempts.
</Step>
</Steps>

## OpenCode V2

OpenCode V2 is listed in the [ACP registry](https://agentclientprotocol.com/registry) and is distributed as a platform
binary rather than an npm package. Install it from **Settings → Agents → Available agents**: Vibe Kanban downloads the
archive for your OS, verifies its SHA-256 and unpacks it into the cache directory on first use, then runs `opencode acp`
over the Agent Client Protocol.

It reuses your existing OpenCode login and configuration, so no separate sign-in is needed. To use a binary you manage
yourself instead, set **Base Command Override** to its path in the agent's configuration.
